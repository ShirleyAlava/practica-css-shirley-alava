# Granito de Café

## Descripción
Sitio web de una cafetería de Santo Domingo, desarrollado como parte de la práctica
"Aplicación de estilos y propiedades CSS".

## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub

## Funcionalidades
- Presentación de la cafetería.
- Navegación entre secciones.
- Menú y tabla de precios.
- Galería de productos.
- Sección de promociones.
- Sección de eventos.
- Formulario de contacto.
